# Montasir Fahim | Developer Portfolio

A responsive, single-page developer portfolio for GitHub Pages. The site presents Montasir Fahim as a backend-focused full-stack developer and competitive programmer, with an emphasis on production systems, competitive programming, and practical engineering outcomes.

## Live Site

[Visit the portfolio](https://montasirfahim.github.io/portfolio/)

## Highlights

- Premium dark interface with glassmorphism cards and emerald, cyan, and violet accents.
- Responsive layout for desktop, tablet, and mobile screens.
- Dynamic hero typewriter cycling between `Full-Stack Software Engineer` and `Competitive Programmer`.
- Animated metric counters for competitive programming and production experience.
- Competitive programming ratings and onsite IUPC highlights.
- Categorized skills across backend, databases, core languages, frontend, DevOps, and tools.
- Featured project cards with impact statements, GitHub links, and visually emphasized Live Demo actions.
- About section with concise icon-led points for development, core technology, and AI/ML interests.
- Education timeline covering HSC, Mathematics, and ICT engineering studies.
- Leadership and mentorship highlights.
- Functional Formspree contact form with client-side validation, sending state, success feedback, and direct Gmail Compose fallback.
- Accessible navigation, focus states, labels, and reduced-motion support.

## Technology

- HTML5
- Tailwind CSS via CDN
- Custom CSS for layout, glass effects, responsive behavior, and animations
- Vanilla JavaScript
- Lucide Icons
- Font Awesome Brands for LinkedIn and Facebook
- Formspree for contact form delivery

## Run Locally

No build step is required.

1. Clone or download the repository.
2. Open `index.html` directly in a browser, or serve the folder with any static web server.
3. Confirm that external CDN resources are available if testing without an internet connection.

For a simple local server with Python:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
