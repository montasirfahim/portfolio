# Montasir Fahim - Full Stack Developer Portfolio

A modern, sleek dark-themed portfolio website built with **Tailwind CSS** and **AOS animations**. Showcasing skills, projects, and professional achievements with ultra-modern UI design.

## Live Demo
[Click Here to Visit](https://montasirfahim.github.io/Portfolio/)

## Features

### Design & UI
- **Dark Theme** with modern gradient backgrounds (slate, cyan, blue, purple)
- **Glassmorphism Effects** with backdrop blur and transparency
- **Smooth Animations** using AOS (Animate On Scroll) library
- **Responsive Design** that works seamlessly on all devices
- **Modern Color Palette** with cyan and blue accents on dark backgrounds

### Sections
1. **Hero Section** - Eye-catching introduction with gradient text
2. **Skills Section** - 8 technical skills with animated progress bars
3. **Projects Section** - 4 showcased projects with hover effects
4. **Social Media** - 6 social platform links with hover animations
5. **About Me** - Personal introduction and resume options
6. **Contact Form** - Integrated with Formspree for direct messaging

### Technology Stack
- **HTML5** - Semantic markup
- **Tailwind CSS** - Utility-first CSS framework
- **JavaScript (Vanilla)** - Interactive features
- **AOS Library** - Scroll animations
- **Font Awesome** - Icon library
- **Formspree** - Contact form backend

### Interactive Features
- **Smooth Scrolling** across all sections
- **Active Link Highlighting** with cyan underline on nav bar
- **Centered Navigation** with only active section highlighted
- **Clickable Logo** redirects to home section
- **Mobile Hamburger Menu** with smooth animations
- **Project Cards** with zoom and overlay effects
- **Social Icons** with scale and glow animations
- **Custom Scrollbar** with gradient styling

### Performance Optimizations
- Lightweight and fast loading
- Optimized animations with hardware acceleration
- Custom gradient progress bars without full-width overflow
- Efficient event listeners and DOM manipulation

## 🛠️ How to Use
1. Clone or download this repository
2. Open `index.html` in your browser
3. All features work locally without any server
4. To modify, edit the HTML, CSS, or JavaScript files accordingly

## 🎨 Customization
- Change colors in `style/style.css` 
- Update content in `index.html`
- Modify animations in `js/script.js`
- Replace images in the `assets/` folder
